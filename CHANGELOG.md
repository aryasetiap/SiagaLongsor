# Changelog

## [0.1.0-research] - 2026-08-07

### Added

- Final single-device dashboard: Overview, Perangkat, Profil Risiko, and Audit Log.
- Authenticated HTTP telemetry ingestion, deterministic server-authoritative risk, and auditability.
- ESP32 integration, isolated presentation environment, responsive frontend, and ECharts sensor visualizations.

### Changed

- Final product scope reset to one deployed device and four product pages.
- Superseded product UX/features were removed from the final scope.
- Presentation build-cache handling was hardened.
